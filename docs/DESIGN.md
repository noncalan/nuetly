# Дизайн-система Nuetly

Источник правды для токенов — `src/app/globals.css`. Этот файл описывает, как ими пользоваться.

## Направление
«Чисто, как Linear»: плотный профессиональный инструмент, не маркетинговый плакат. Главный визуальный элемент — цифры (таймер, баллы, отсчёт). Никаких градиентных пятен, glassmorphism, эмодзи, сеток «три карточки с иконкой», выдуманных отзывов и цифр пользователей.

## Цвета: у каждого одна роль
| Класс | Роль |
|---|---|
| `bg-accent`, `text-accent-ink`, `bg-accent-soft` | бренд, главные действия, выбранное, прогресс, завершённость |
| `text-accent-text` | любой ТЕКСТ акцентного цвета (ссылки). Никогда не `text-accent` для текста |
| `bg-success`, `text-success-ink`, `bg-success-soft` | только «верно» и положительная динамика |
| `text-gold`, `text-gold-ink`, `bg-gold-soft`, `border-gold` | только отметки (флажки) на вопросах |
| `bg-danger`, `text-danger`, `bg-danger-soft` | ошибки, слабые темы (< 50 %), последние 5 минут таймера |
| `bg-canvas` | фон страницы |
| `bg-surface` + `border border-line` + `shadow-card` | карточка уровня e1 |
| `bg-subtle` | вкладыши: шапки таблиц, раскрытые решения, боковая панель |
| `bg-muted` | дорожки прогресса, hover |
| `text-ink` / `text-ink-2` / `text-ink-3` | основной / вторичный / подписи |
| `border-control-border` | границы контролов, которым нужен контраст 3:1 |

## Типографика
`text-display` (96, отсчёт) · `text-score` (64) · `text-stat` (32) · `text-timer` (22) · `text-h1` (28, заголовок страницы) · `text-h2` (15/600, заголовок любого блока) · `text-reading` (18/30, условие задачи) · `text-option` (16/24) · `text-body` (14) · `text-meta` (13) · `text-caption` (12/500).

**Моноширинный (`font-mono tabular-nums`) — только для цифр.** Слова («дней», «мин», «вопросов», «скоро») — обычным шрифтом. Никаких капслок-подписей моноширинным.

## Формы и отступы
Скругления: `rounded-md` чипы и ячейки · `rounded-lg` кнопки и сегменты · `rounded-xl` карточки, варианты ответа, таблицы · `rounded-2xl` только диалоги и шторки.
Отступы шагами 4 / 8 / 12 / 16 / 24 / 32 / 48. Между блоками `gap-8`, заголовок → содержимое `mt-3`, шапка страницы → первый блок `mt-8`.
Заголовок страницы: подпись `text-meta text-ink-3`, затем `h1.text-h1`.

## Движение
- Утилиты: `ui-stagger` (`style={{ "--i": n }}`, n ≤ 5, одноразовое появление), `ui-enter` (появление при монтировании), `ui-backdrop` + `ui-modal`, `ui-sheet`, `ui-progress` (`--progress` 0..1 внутри дорожки с `overflow-hidden`), `ui-wipe`.
- Анимируются только `transform` и `opacity` (плюс плавная смена цвета). Никогда `transition-all`.
- Нажатия: `active:scale-[0.97]` на кнопках, `0.95` на мелких чипах, `active:bg-muted` на строках во всю ширину.
- Действия с клавиатуры на экзамене (A–E, стрелки, F) не анимируются.

## Компоненты
- Кнопки: `Button` / `buttonClasses` из `@/components/ui/button` (`primary` / `secondary` / `ghost`, размеры `sm` / `md` / `lg`).
- Обёртка приложения: `AppShell` из `@/components/app-shell/app-shell`.
- Формулы: `MathText` из `@/components/math-text` (текст с `$…$`).
- Цифры внутри текста: `MonoDigits` из `@/components/dashboard/mono-digits`.

## Код
Именованные экспорты, `type Props`, `cn` из `@/lib/cn`, константы вместо магических чисел, файлы < 300 строк, без `console.log`, без новых зависимостей без нужды. Серверные компоненты по умолчанию; не вызывать `Date.now()` / `new Date()` при рендере (включён `cacheComponents`). Интерфейс на русском, задачи — на английском.

## Доступность
Настоящие заголовки, видимый фокус, цели ≥ 24 px (`pointer-coarse:min-h-11` на сенсорных), смысл не только цветом, контраст по токенам выше, `aria-*` по паттернам WAI-ARIA.
