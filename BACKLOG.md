# Бэклог автономной работы

Порядок = приоритет. Каждый пункт закрывается целиком: код → `tsc` / `eslint` / `next build` → проверка в браузере → коммит → пуш в `main` (автодеплой на https://nuetly.noncalan.xyz) → проверка прода.
Всё на демо-данных; никаких выдуманных дат NU, отзывов, цифр пользователей и «официальных» баллов. Общий план и решения — в [PLAN.md](PLAN.md).

## Итерация 1 — каркас платформы
- [x] **Лендинг** на `/`: продукт вместо плаката. Hero с живой композицией из настоящих компонентов (таймер, полоска ответов, отсчёт), «как это работает», превью экзамена/разбора/аналитики, тарифы (Free / Plus / Pro, без работающей оплаты), FAQ, футер с дисклеймером «не связан с Nazarbayev University». Кнопка «Открыть демо» → `/dashboard`.
- [x] **Каталог пробных** `/mocks`: список пробных со статусом (пройден / не начат / скоро), лучшим результатом, кнопками «Начать» / «Разбор». Пункт меню «Пробные экзамены» ведёт сюда.
- [x] **Практика** `/practice`: выбор раздела, темы и сложности → сессия из 10 задач без таймера → объяснения после набора → итог.
- [x] **Программа** `/learn` + урок `/learn/[slug]`: полное дерево тем Math и CT с прогрессом; один полноценный урок (теория, формулы, разобранный пример, мини-практика).
- [x] **Аналитика** `/analytics`: тренд по попыткам, карта тем, точность по сложности, время по разделам.

## Итерация 2 — путь пользователя
- [x] Вход / регистрация (`/login`, `/register`) — только интерфейс, без настоящей авторизации, с пометкой «демо».
- [x] Онбординг `/onboarding`: класс → срок экзамена → часы в неделю → переход на дашборд.
- [ ] Трекер поступления `/admissions`: чек-лист этапов без выдуманных дат, ссылки на официальные страницы NU.
- [x] Профиль и настройки `/settings`: тема, язык интерфейса (RU активен, KZ/EN «скоро»), данные профиля.
